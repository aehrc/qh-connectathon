Four pieces, and every prepopulated item uses all four. Launch context says who the patient is; the query fetches data; FHIRPath picks the bit you want; initialExpression drops it into the item. The answer is only a starting value: the user can overwrite it. We'll go query first, then FHIRPath, then put it in the form, then run it.

This sits on the root of the Questionnaire, once per form. It's a declaration: the form needs a Patient called patient. The renderer or the EHR launch supplies it. After that, any expression in the form can use the percent-patient variable.
